# Shopify Collection Filters (No App)

Custom collection page filters using Shopify native filtering system.
No third-party app required.

## Features
- Price filter
- Variant-based filters (Color, Size)
- AJAX filtering
- Mobile responsive

## Tech Stack
- Shopify Liquid
- Vanilla JavaScript
- CSS

## Installation
1. Copy files into your Shopify theme
2. Enable filters in Shopify Search & Discovery app
3. Use on collection templates

## Use Case
Perfect for stores that want fast, lightweight filtering without paid apps.
